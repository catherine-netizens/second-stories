SECOND STORIES - CART FIXED CLEAN

1. Extract folder ini.
2. Struktur sudah dibuat langsung:
   Second-Stories-CART-FIXED-CLEAN/
   ├── homepage.html
   ├── cart.html
   ├── cart.js
   ├── cart.css
   ├── shared.js
   └── server/
       ├── server.js
       ├── package.json
       └── .env.example

3. Buat file .env di folder server, berdasarkan .env.example.
   Jika MySQL AMMPS tidak memakai password:
   DB_PASSWORD=

4. Buka CMD pada folder:
   ...\Second-Stories-CART-FIXED-CLEAN\server

5. Jalankan:
   npm install
   npm start

6. Buka:
   http://localhost:3000

PENTING:
- Jangan membuka cart.html dengan double-click.
- Jangan menjalankan server dari folder parent.
- File .env asli sengaja tidak disertakan.
